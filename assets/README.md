## 1. Static Asset Catalog

This directory documents and mirrors the static brand assets utilized across the Waypoint platform:

- **Logo (`public/psk-logo.svg`)**: Official high-resolution PSK Sportsbook brand mark.
- **Favicon (`public/favicon.svg`)**: Distinctive Waypoint platform radar icon.
- **Icon Sprite System (`public/icons.svg`)**: Optimized vector symbol set for sports categories (football, tennis, basketball), live indicators, and navigation badges.
- **Portals UI Graphics (`public/assets/`)**: Pre-compiled asset bundle used by the Vite build pipeline during production deployment.
