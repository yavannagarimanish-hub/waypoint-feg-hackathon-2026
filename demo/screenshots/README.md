### 2. Live Match Rooms & Non-Monetary Social Predictions

### 4. Continue Playing (Primary Re-entry Experience)

### 5. Operator Admin Portal (`/admin`)
- **Focus**: Real-time Operator Dashboard featuring live customer flight radar, Universal Funnel drop-off visualization, Friction Root Cause analysis, and Grounded AI Session Investigator.
